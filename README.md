Завдання 1 Циклічний зсув

std::span<T> дає змогу працювати з різними типами масивів без копіювання даних. Тому одну шаблонну функцію можна застосувати до vector, array і звичайного масиву.


Завдання 2 Розбиття рядка

std::string_view не зберігає власні дані, а лише посилається на рядок. Якщо вихідний рядок знищити, усі представлення стануть недійсними. Тому потрібно зберігати вихідний рядок протягом усього часу використання string_view.


Завдання 3

Функція utf8_prefix(s, 2) повертає два повні символи, враховуючи їхню байтову структуру. Натомість substr(0, 3) відбирає три байти, що може розірвати UTF-8 символ і створити некоректний рядок.

Завдання 7 числа Тетраначчі

Найбільший індекс, для якого результат поміщається в std::int64_t, - 70.

T(70) = 7057305768232953720, а T(71) уже не поміщається в цей тип. Перед додаванням програма перевіряє можливість переповнення.


Завдання 8

Функція create скорочує дріб і робить знаменник додатним. Завдяки цьому дроби можна порівнювати перехресним множенням. Оператор operator<=> забезпечує порівняння та дає змогу використовувати std::sort.

Для великих значень long long необхідно додатково перевіряти переповнення під час арифметичних операцій.
